# Sarthak Mehta — React + Three.js Static Portfolio

Static portfolio built with React, Vite, Three.js / React Three Fiber, and CSS.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Render Static Site

- Build Command: `npm install && npm run build`
- Publish Directory: `dist`

No backend or database is required.

## Add your existing assets

Copy these files into `public/`:
- `sarthak.jpeg`
- `sarthak.pdf`

Copy project screenshots into `public/projects/` using the filenames already referenced by the app.

Copy the 24 certificate images into `public/certificates/`:
`certificate1.jpeg` through `certificate24.jpeg`.

The project live links, certificate descriptions, terminal commands, contact email, GitHub and LinkedIn are already configured.
